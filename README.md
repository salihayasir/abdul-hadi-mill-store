# Abdul Hadi Mill Store

Product catalogue website for Abdul Hadi Mill Store, a belts and bearings shop on Main Sundar Raiwind Road, Lahore.

Customers browse timing belts, V-belts, poly belts, conveyor belting, belt joints and bearings, then ask for price and stock on WhatsApp (0321-9999322). There is no online checkout.

## Files

- `index.html`: the complete website. Styles, scripts and product photos are all inside this one file.
- `favicon.svg`: the browser tab icon.

## Pages

The site is a single page with hash links:

- `#home` home page
- `#products` all products, with search and filters
- `#cat-timing-belts`, `#cat-bearings` and so on: one product range
- `#p-<product-id>`: one product with its specification
- `#identify`: form that writes a WhatsApp message to identify a part
- `#brands`, `#contact`

## Run locally

Open `index.html` in any browser. No install or build step is needed.

## Publish with GitHub Pages

1. Push these files to the `main` branch.
2. Open the repository Settings, then Pages.
3. Under Build and deployment, choose "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
4. The site goes live at `https://<username>.github.io/<repository-name>/` after a minute or two.

## Before going live

Photos and some specifications are placeholders. Replace them with the shop's own photos and confirmed details.
